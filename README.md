# dsh-live-dictation

按住 <kbd>Alt</kbd> 说话，文字**边说边出现在输入框里**，并且**整段持续自我修正**，松开即定稿 —— 不用再点"开始录音 / 停止录音"。

一个 DeepSeek Harness 的插件（bundle + Web 客户端扩展），复用内置的语音识别服务，不额外依赖任何云 API。

## 特性

- **按住 Alt 即说**：按下开始、松开定稿；<kbd>Esc</kbd> 或按住时按其他键可取消。
- **实时出字**：识别结果直接写进当前会话的输入框，不是浮层预览。
- **整段自我修正**：每次新增约 1.2 秒语音就把**整段话**从头重新识别一遍，用新结果整体替换上一版文字；句子越长，重识别间隔自动放宽（最多 4 秒），避免越说越卡。
- **松手定稿**：松手时再跑一次整段识别，最终文本按整句给出标点与断句。
- **鼠标也能用**：按住输入框右侧的状态胶囊同样可以听写。
- **不串音**：音频图不接扬声器输出，保留浏览器回声消除，外放的声音不会被录进去。
- **原生体验**：只占输入框右侧的一个小胶囊，跟随主题；不替换原生麦克风按钮，可与它并存。

## 安装

发布后，在 DeepSeek Harness 的插件市场里搜索 `dsh-live-dictation` 安装即可。

如果安装后没有立刻出现，重启一次 DeepSeek Harness。

## 使用

1. 光标放进要听写的会话输入框。
2. 按住 <kbd>Alt</kbd> 说话，文字会边出现边被整段改写。
3. 松开 <kbd>Alt</kbd> 定稿。

输入框右侧的胶囊会显示状态（正在打开麦克风 / 正在听 / 转写中），失败时直接显示原因。

## 前提

- 已配置可用的语音服务（设置 → 语音输入，内置 SenseVoice 即可），并已给应用麦克风权限。
- 首次使用可能需要下载模型，准备期间胶囊会提示等待。
- 需要 DeepSeek Harness `>= 0.2.0`（`engines.dsh`）。

## 工作原理

内置语音栈没有流式协议：一次接收完整 WAV，返回一段文字。插件因此在按住期间不断把"到目前为止的全部录音"编码为 16 kHz 单声道 PCM16 WAV，交给与内置麦克风按钮相同的 `speech` Remote；每次返回都通过 `inputActions.insertText(text, span)` 覆盖上一版草稿，从而实现"边说边改"。

更多细节见 [docs/DETAIL.md](docs/DETAIL.md)。

## 开发

本仓库本身就是一个可安装的 bundle 目录：把这个目录（而不是 npm 包名）交给插件管理器安装，它会被以 `link:` 方式接进当前 profile，改完文件即时生效。

改完 `client.js` 后，用插件管理器把 bundle 禁用再启用，即可让客户端代码从磁盘重新加载，无需重启应用。
