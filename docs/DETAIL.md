# 按住 Alt 语音输入

在输入框里按住 <kbd>Alt</kbd> 说话，文字边说边出现在输入框里；松开即定稿。不需要点"开始录音 / 停止录音"。

## 用法

1. 先把光标放进要听写的会话输入框。
2. 按住 <kbd>Alt</kbd>，正常说话。
3. 文字先粗后精：大约每新增 1.2 秒语音，插件会把**这一段话从头重新识别一次**，用新结果**整体替换**刚才那段文字；句子越长，重识别间隔会自动放宽到最多 4 秒。
4. 松开 <kbd>Alt</kbd> 定稿（松手时再跑一次整段识别，所以最终文本是按整句给的标点与断句）。
   按住时按 <kbd>Esc</kbd>（或任意其他键）可取消本次听写。

麦克风打开期间，输入框右侧会出现一个状态胶囊：打开麦克风、正在听、转写中都有提示，失败时直接把原因写在上面。用鼠标按住这个胶囊也能听写。

## 原理

内置语音栈没有流式协议：它每次接收一个完整 WAV，返回一段文字。因此本插件在麦克风打开期间，不断把"到目前为止的全部录音"编码成 16 kHz 单声道 PCM16 WAV，交给内置麦克风按钮用的同一个 `speech` Remote，并把结果整体替换到输入框里。

- 采集：`getUserMedia` + `ScriptProcessorNode`，浏览器内重采样到 16 kHz（盒式滤波，带小数进位的连续性）。
- 替换：先用 `captureInsertion()` 记住插入点，之后每次更新都用 `insertText(text, { start, end, draftRev })` 覆盖上一版草稿（这就是"边改边写"的实现方式，而不是只往后追加）。
- 音频图**不接扬声器输出**：Chromium 一旦把麦克风流接到 `context.destination` 就会关闭回声消除，外放的声音会被当成麦克风输入录进去；这里只接到一个虚拟的 `MediaStreamAudioDestination`。

## 依赖

- 需要配置可用的语音服务（设置 → 语音输入；内置 SenseVoice 即可）。首次使用可能需要下载模型，准备期间状态胶囊会提示等待。
- 给应用麦克风权限。
- 只监听 <kbd>Alt</kbd>：AltGr（Ctrl+Alt）组合键与系统快捷键不受影响；有模态弹窗时不会启动。

## 限制

- 识别速度取决于语音模型与 CPU：长句的中间结果可能滞后几百毫秒到几秒，最终以松手那次为准。
- 单次按住最长 60 秒，超过会自动收尾。
- 写入的是普通草稿文本：撤销、引用、附件照常工作；插件不会在事后把听写内容从草稿里移除。
